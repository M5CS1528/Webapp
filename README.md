# Simple Interest Calculator

## Project Overview

This project is a simple interest calculator that computes the interest earned on a principal amount over a specified time period.

## How It Works

The calculator uses the following inputs:

- **Principal (P):** The initial amount of money.
- **Rate of Interest (R):** The annual interest rate in percentage.
- **Time (T):** The time period in years.

The simple interest is calculated using the formula:

**Simple Interest = (P × R × T) / 100**

The final amount is calculated as:

**Total Amount = Principal + Simple Interest**

## Features

- Accepts principal, rate of interest, and time period as input.
- Calculates simple interest quickly.
- Displays the calculated interest and total amount.
- Implemented as a simple Bash-based calculator.

## Usage

Run the calculator and enter the requested values for principal, rate of interest, and time period.

## Project Purpose

The project demonstrates basic Bash scripting, user input handling, arithmetic operations, and command-line application development.
